## Otimização de Imagens

Após download, otimize as imagens:

1. **Redimensione** para tamanhos exatos especificados
2. **Comprima** usando ferramentas como:
   - TinyPNG (tinypng.com)
   - Squoosh (squoosh.app)
   - ImageOptim (imageoptim.com)
3. **Converta para WebP** (opcional, para melhor performance)
4. **Renomeie** exatamente como especificado acima
5. **Coloque na pasta** `images/` do projeto
